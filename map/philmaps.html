PhilMaps / Because: Editor Tool Guide

Use this page as a reference for operating the Because argument-map editor. It explains how to add and edit boxes, move items, change display settings, zoom, and save your work.

Open the Editor PhilMaps Website

1. Add, Edit, and Delete Boxes

Action How to do it
Add a box Select a box and press Enter.
Add a co-premise box Select a box and press Tab.
Edit box text Select the box and press F2 or Space.
Delete a box Select it and press Delete.
Add an objection Select a box and press Alt + O.
Add a sticky note Select a box and press Alt + N.
Undo Press Ctrl + Z on Windows.
Redo Press Ctrl + Y on Windows.

2. Move and Resize Boxes

Action How to do it
Move a box Select the box. Open Edit → Move… or press M. Select the destination box or click an empty area of the map to position it there.
Move a box left or right Use Edit → Move left or Edit → Move right.
Make a box wider Use Edit → Wider claim.
Make a box narrower Use Edit → Narrower claim.
Detach a box Select it and press D.
Collapse or expand a branch Select the box and press F.
Select multiple boxes Hold Shift and use the arrow keys.
Navigate between boxes Use the arrow keys.

3. Change Colors and Display Settings

Action How to do it
Switch between light and dark mode Press Shift + T, or use the View menu.
Use high-contrast colors Select View → High-contrast map colors.
Show or hide claim numbering Use the numbering option in the View menu.
Change a claim number to a custom label Click the claim number and enter a label.
Add or edit a connector label Select the relevant claim and press L.
Enable neutral connectors Select View → Allow neutral connectors.
Toggle an item's type Select the item and press T or Alt + T.
Note: The high-contrast option changes the colors used to display the map. It does not permanently change the saved map file. If you want to change an individual box's background, look for the relevant claim-formatting controls in the editor.

5. Open and Save Files

Open an Existing Map

  1. Open the Because editor.
  2. Select File → Open.
  3. Select your saved .mup file.

You can also drag a .mup file into the editor window.

Save an Editable Map

  1. Open the File menu.
  2. Select Save.
  3. Choose where to save the file if prompted.
  4. Keep the file with its .mup extension.

Export or Print a PDF

  1. Open the editor's print command, if available.
  2. In the browser's print dialog, choose Save as PDF.
  3. Select the destination and save.
Important: A .mup file is editable. A PDF is intended for viewing or printing and is not a replacement for the editable map.

Save to Google Drive or OneDrive

If the cloud-storage options are enabled in your editor, use the relevant File menu option and follow the sign-in and file-selection prompts. You can also save a local copy to your computer.
