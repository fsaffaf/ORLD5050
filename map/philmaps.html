PhilMaps: How to Create an Argument Map

PhilMaps teaches you how to organize an argument visually. Its argument-mapping editor, called Because, lets you create boxes containing claims and connect them to show how reasons support or challenge a main claim.

Open the Because Editor Learn the Basics

You do not need to install software or create an account to begin. You can build your map in your browser, save an editable file, and export a printable version.

1. Understand the Structure of an Argument Map

An argument map displays the relationship between a conclusion and the reasons offered in support of it. The main claim appears above its supporting reasons and objections.

Visit the PhilMaps website to view its interactive argument-map examples.

Important Parts of the Map

  • Main claim: The position you want your audience to accept.
  • Supporting reason: A statement explaining why the main claim should be accepted.
  • Co-premises: Two or more claims that work together to support another claim.
  • Objection: A statement that challenges a claim or its supporting reasoning.
  • Implicit claim: An assumption that the argument relies on but does not explicitly state.

2. Create and Edit Claim Boxes

Each box contains one claim: a statement that can be evaluated as true or false. Keep each box focused on one idea.

Action How to do it
Create a supporting reason Select a claim and press Enter.
Add a co-premise Select a claim and press Tab.
Edit a claim Select the claim and press F2 or Space.
Create an objection Select a claim and press Alt + O.
Move a claim Drag it to a new position, or use the Edit menu's Move command.
Remove a claim Select it and press Delete.
Disconnect a claim Select it and press D.
Collapse or expand a branch Select the claim and press F.
Undo an action Press Ctrl + Z on Windows.
Redo an action Press Ctrl + Y on Windows.
Important: Pressing Tab while the map has focus creates a co-premise. To move out of the map and back to the menus, press Escape.

3. Understand and Change Colors

In Because, bracket colors communicate the logical relationship between claims. They are not just decorative colors.

Visual feature Meaning How to use it
Green rounded bracket Support Connects reasons that support a claim.
Red square bracket Objection Connects a challenge to a claim or argument.
Blue flat bracket Neutral connector Connects claims without specifying support or objection.
Dashed claim border Implicit claim Indicates an unstated assumption.
Yellow sticky note Additional note Stores contextual information outside the argument itself.

Change the Appearance of Your Map

  • Switch between light and dark mode: Open the View menu or press Shift + T.
  • Improve color contrast: Open View → High-contrast map colors.
  • Show or hide claim numbers: Use the numbering option in the View menu.
  • Change a claim number to a custom label: Click the claim number and enter a short label.
  • Add a sticky note: Select a claim and press Alt + N.
  • Label a connector: Select the claim and press L.
  • Enable neutral connectors: Select View → Allow neutral connectors. This option is off by default.
Remember: Green means support, red means objection, and blue means neutral when neutral connectors are enabled. The shapes of the brackets also differ, so do not rely on color alone.

5. Save Your Argument Map

Option A: Save an Editable File

  1. Open the Because editor.
  2. Open the File menu.
  3. Select Save.
  4. Save the map as a .mup file on your computer.

The .mup file preserves your editable argument map. You can reopen it later using File → Open or by dragging the file into the editor.

Option B: Save a PDF

  1. Open your completed map.
  2. Use the editor's print option, if available.
  3. In the browser's print window, select Save as PDF.
  4. Choose a location and save the PDF.

A PDF is useful for viewing and submitting your map, but it is not an editable replacement for the original .mup file.

Option C: Use Cloud Storage

Google Drive and Microsoft OneDrive integrations are available in supported deployments of Because. Use the relevant File menu option if it is available and follow the prompts to connect and save your map.

Do not rely only on autosave. Because keeps a browser recovery copy, but this is not the same as saving a file you can retrieve later. Save your work to a location you control.

6. Recommended Workflow for Your Argumentative Essay

  1. Write your main claim. State the position you want to defend.
  2. Add your supporting reasons. Select the main claim and press Enter to add a reason.
  3. Add supporting claims. Use co-premises when two or more claims must work together to support a conclusion.
  4. Identify assumptions. Ask what must be true for each reason to support the claim.
  5. Add objections. Consider reasonable arguments against your position.
  6. Review the logic. Check whether each reason actually supports the claim it connects to.
  7. Save your map. Save the editable file and export a PDF if required.
